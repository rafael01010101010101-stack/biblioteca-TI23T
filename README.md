# Sistema de Gerenciamento de Biblioteca (Windows Forms & MySQL) 📚 Windows Forms (.NET) com interface gráfica completa.
- **CRUD Completo:** Implementação das quatro operações essenciais de banco de dados em uma tabela — **C**reate (Inserir), **R**ead (Consultar), **U**pdate (Atualizar) e **D**elete (Excluir).
- **Persistência Relacional:** Integração ativa com o servidor MySQL para garantir que todas as alterações na interface sejam salvas no banco de dados.
- **Experiência do Usuário (UX/UI):** Manipulação de componentes visuais como DataGridView para listagem de dados, além de caixas de texto e botões dinâmicos.

## 🛠️ Stack Tecnológica
- **Linguagem:** C# (.NET)
- **Interface Gráfica:** Windows Forms Application
- **Banco de Dados:** MySQL
- **Ambiente de Desenvolvimento:** Microsoft Visual Studio

---

## 📈 Evolução Técnica e Aprendizados
Este projeto representa a minha transição das aplicações via terminal para o desenvolvimento de softwares visuais com persistência de dados, consolidando conceitos fundamentais de mercado:
1. **Programação Orientada a Eventos:** Compreensão de como o código reage às ações do usuário (clicar em botões, carregar a página ou selecionar itens).
2. **Arquitetura CRUD:** Estruturação de queries SQL completas (`INSERT`, `SELECT`, `UPDATE`, `DELETE`) executadas diretamente através dos componentes da interface gráfica.
3. **Sincronização de Dados:** Atualização automática de tabelas visuais (como o DataGridView) assim que uma alteração é feita no banco de dados.
